# Contributing

This repository is the humanebench.ai website. It is not open to outside changes. Please do not open pull requests against it.

- To suggest a correction to the site, email info@buildinghumanetech.com.
- To contribute to the benchmark itself (scenarios, ratings, code, translations), go to [buildinghumanetech/humanebench](https://github.com/buildinghumanetech/humanebench/blob/main/CONTRIBUTING.md).
